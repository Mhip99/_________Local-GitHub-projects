## 可搬性改修
- **`起動_Kotonoha-ハブ.bat` をパス設定化**（ユーザー名ハードコード排除）：
  - `CACHE`（索引キャッシュ）既定＝`%~dp0_Index`、`LTDIR`（LanguageTool）既定＝`%LOCALAPPDATA%\Kotonoha-LT`。
  - 環境別の上書きは **`_kotonoha-paths.bat`**（任意・Git管理外）で `set CACHE=` / `set LTDIR=`。雛形 `_kotonoha-paths.bat.sample` をコミット。
  - LanguageTool は版フォルダを **ワイルドカード検出**（`jdk*` / `LanguageTool-*`）＝版非依存。存在時のみ `start /b` で起動（ハブ終了で一緒に停止）。
  - **Masaaki 環境**には `_kotonoha-paths.bat`（Git管理外）を置き、`CACHE` を既存の共有 Index（`…\TM manaegment\…\Kotonoha\Index`）に設定＝従来挙動を維持。
- **`_install-LanguageTool.bat`**：ポータブルJRE21＋LanguageTool を `%LOCALAPPDATA%\Kotonoha-LT` へ自動ダウンロード・展開（約290MB・任意）。
- **`.gitignore`** に `_kotonoha-paths.bat`（machine固有）・`_Index/`（ローカル索引キャッシュ）を追加。
