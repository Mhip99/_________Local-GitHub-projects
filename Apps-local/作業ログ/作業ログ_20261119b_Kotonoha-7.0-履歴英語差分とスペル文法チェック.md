## Feature 1：翻訳履歴ペインの英語差分（MTセグメント用）
- `wdiff(old,new)`（単語LCS・空白保持）＋ `diffEnHTML(pastEn,curEn)` を追加。各履歴エントリの英語行を、**過去英語=正**、**現在原文の新規/変更語を取り消し線**で描画。各断片 `esc()`。版履歴（同一原文）は差分ゼロ＝プレーン、あいまい候補（MT）で差分表示。
- CSS `.hsrc .hadd{text-decoration:line-through;color:var(--faint)}`。
- テンプレ＋記事に実装。クライアントのみ＝ハブ再起動不要。

## Feature 2A：スペル・文法チェックのON/OFF＋ブラウザ内蔵スペルチェック
- 操作行に **「スペル・文法チェック」チェックボックス**（`#spellchk`・既定OFF・localStorage `kotonoha-spellcheck`）。
- ON時：訳文欄 `.jaedit` に `spellcheck="true"`（英語スペル等の波線）＋ `body.spellon` 付与（Bのボタン/⚠表示を解放）。OFFで false。
- `SPELL` 変数（テンプレ=let、記事=var）。render の jaedit に `spellcheck="${SPELL?...}"`。
- 注意書き（title）：高度/クラウド系スペルチェック・拡張はOFF推奨（機密の外部送信回避）。クライアントのみ。

## Feature 2B：Claude チェックパス（既存MTと同じ人介在・外部送信なし）
- **サーバー（projects.py）**：
  - `POST /api/check-todo`：`{art,items:[{i,en,ja}]}` を `_wip/<art>.check-todo.json` に書き出し（instructions 同梱）。
  - `GET /api/check-done`：`_wip/<art>.check-done.jsonl`（各行 `{"i":index,"issues":[{"field":"en|ja","msg","suggest"}]}`）を読んで返す。
  - いずれも Host 検証＋トークン認証下。
- **クライアント**：`body.spellon` のとき操作行に **「チェック用に書き出し」「結果を反映」**（`.spellbtn`）を表示。
  - 書き出し：全SEGの `{i,en:plain,ja:jaValue}` を POST→ファイル生成（alert でパス案内）。
  - 反映：GET→`CHECKS[i]=issues`→`paintChecks()` が該当行の #idx セルに **⚠バッジ**（`title`＝指摘＋修正案・プレーン＝XSS不可）。`render` をラップして再描画後も⚠維持。
- **運用ループ**：ユーザーが「書き出し」→ `_wip\<art>.check-todo.json` を Claude が点検 → 同フォルダに `<art>.check-done.jsonl` を作成 → ユーザーが「結果を反映」。MTフローと同型。
