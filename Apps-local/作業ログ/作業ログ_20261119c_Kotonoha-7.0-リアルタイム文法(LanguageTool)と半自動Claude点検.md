## ★重大バグ修正（urllib シャドーイング）
`/api/lt` で関数内 `import urllib.request` を書いたため、Python が **do_POST 全体で `urllib` をローカル変数化**し、冒頭 `urllib.parse.urlparse(self.path)` が `UnboundLocalError`→**全POSTが停止**（save-edits/check-todo 等も空返答）。修正＝serve内の `import ... urllib.parse, urllib.request, ...` に集約し、関数内 import を削除。再発防止の教訓：**関数内 import は同名トップレベルを関数スコープでシャドーする**。

## Option 1：英語リアルタイム文法パネル（方式P）
- 画面下部固定の `#ltbar`。訳文欄 `.jaedit` の **input をデバウンス(700ms)→`/api/lt`(language=auto)→フォーカス中セグメントの指摘＋修正案を一覧**表示。`{n}` プレースホルダは送信前に除去。SPELL ON 時のみ。閉じる×付き。**LT 出力は全て esc()**（未信頼データ）。
- `focusin` でも即時点検。SPELL OFF でバー非表示。

## Option 2：日本語＝半自動 Claude 点検
